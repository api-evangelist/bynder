# Bynder (bynder)

Bynder is a cloud-based digital asset management (DAM) platform that helps organizations store, organize, distribute, and analyze brand and marketing assets. The Bynder REST API enables developers to programmatically manage assets, metadata, collections, taxonomies, workflows, and brand guidelines, with OAuth 2.0 authentication against each customer's portal domain.

## APIs

### Bynder API

REST API for managing digital assets, metaproperties, collections, taxonomies, brand guidelines, and asset workflows in a Bynder portal. Authentication uses OAuth 2.0 with authorization code, client credentials, and refresh token flows.

- **Human URL:** [https://developers.bynder.com](https://developers.bynder.com)
- **Base URL:** `https://yourportal.bynder.com/api`
